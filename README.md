## 🧭 How I work

I build almost everything with AI coding agents (Cursor, Claude Code, Codex, Kiro and friends) as my team.
My job is the architecture, the protocols and the review; the agents handle most of the typing.
That lets one person maintain a whole ecosystem: a Go gateway, Rust/Wasm plugins, desktop and mobile clients, and embedded firmware.

## 🚀 Now: the AI Proxy ecosystem

A self-hosted gateway that puts every AI provider behind one API, extended by plugins.

| Project | What it is |
|---|---|
| [ai-proxy-releases](https://github.com/veildawn/ai-proxy-releases) | Packaged releases of ai-proxy-service |
| [ai-protocol](https://github.com/veildawn/ai-protocol) | Dependency-free Go library that converts request, response and SSE bodies between AI API formats |
| [ai-model-registry](https://github.com/veildawn/ai-model-registry) | Provider, model and pricing registry |
| [ai-provider-plugins](https://github.com/veildawn/ai-provider-plugins) | Integration and provider plugin marketplace (Wasm) |
| [ai-proxy-automations](https://github.com/veildawn/ai-proxy-automations) | Automation and background-task plugins |
| [homebrew-tap](https://github.com/veildawn/homebrew-tap) | `brew install` for ai-proxy-service |
