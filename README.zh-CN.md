## 🧭 我的工作方式

我几乎所有代码都交给 AI 编码代理来写（Cursor、Claude Code、Codex、Kiro 等），它们就是我的团队。
我负责架构、协议设计和代码评审，大部分敲代码的活由代理完成。
这样一个人也能维护一整套生态：Go 网关、Rust/Wasm 插件、桌面和移动客户端，还有嵌入式固件。

## 🚀 正在做：AI Proxy 生态

一个可自托管的网关，用统一的 API 接入所有 AI 服务商，并通过插件扩展。

| 项目 | 简介 |
|---|---|
| [ai-proxy-releases](https://github.com/veildawn/ai-proxy-releases) | ai-proxy-service 的打包发布版本 |
| [ai-protocol](https://github.com/veildawn/ai-protocol) | 零依赖的 Go 库，在不同 AI API 格式之间转换请求、响应和 SSE 流 |
| [ai-model-registry](https://github.com/veildawn/ai-model-registry) | 服务商、模型与价格注册表 |
| [ai-provider-plugins](https://github.com/veildawn/ai-provider-plugins) | 集成与服务商插件市场（Wasm） |
| [ai-proxy-automations](https://github.com/veildawn/ai-proxy-automations) | 自动化与后台任务插件 |
| [homebrew-tap](https://github.com/veildawn/homebrew-tap) | 用 `brew install` 安装 ai-proxy-service |
